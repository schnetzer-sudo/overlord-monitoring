# Sollliste der Datenbank-Indizes
#
# Erhoben am 21.08.2026 aus information_schema.STATISTICS der Testkopie.
# Quelle ist die Datenbank, nicht ein Dokument.
#
# Bewacht von IndexbestandDbIT (@Tag("db")), und zwar in BEIDE Richtungen:
#
#   ein Eintrag dieser Liste fehlt in der Datenbank    -> rot
#   die Datenbank traegt einen Index, der hier fehlt   -> rot
#
# Die zweite Richtung ist der Grund fuer diese Datei. Am 20.08.2026 fehlte nichts in der
# Datenbank — es fehlten fuenf Eintraege in der Dokumentation, achtzehn Tage lang, und die
# falsche Liste ist in einen Arbeitsauftrag eingegangen. Ein Test, der nur die erste
# Richtung prueft, waere die ganze Zeit gruen geblieben.
#
# Diese Datei wird nicht passend gemacht. Schlaegt der Test an, ist zuerst zu klaeren, WER
# sich geaendert hat: die Datenbank oder diese Liste. Es wird kein Index angelegt, geaendert
# oder geloescht, um einen Testlauf gruen zu bekommen — ein unerwarteter Befund ist ein
# Befund und keine Aufgabe.
#
# ── Format ──────────────────────────────────────────────────────────────────────────────
#
# Zwei Satzarten, mit Semikolon getrennt, ohne Anfuehrungszeichen. Leere Zeilen und Zeilen,
# die mit einer Raute beginnen, sind Kommentar. Bewusst schlichter Text: keine
# Serialisierungsbibliothek, damit die Datei in jedem Diff lesbar bleibt.
#
#   tabelle;<schema>;<Tabelle>
#       Diese Tabelle steht unter Bewachung. Nur fuer die hier gefuehrten Tabellen prueft
#       der Test die Gegenrichtung.
#
#   index;<schema>;<Tabelle>;<Indexname>;<Spalte1,Spalte2,...>;<eindeutig: ja|nein>
#       Spalten in der Reihenfolge von SEQ_IN_INDEX. Eindeutig heisst NON_UNIQUE = 0;
#       PRIMARY ist immer eindeutig.
#
# <schema> ist ein logischer Name, kein Schemaname: glassfish ist das Quellschema, monitor
# das eigene. Die tatsaechlichen Namen kommen aus den Umgebungsvariablen
# (DatabaseProperties). Die Liste gilt damit auch dort, wo die Schemata anders heissen als
# in der Testkopie.
#
# ── Namen ───────────────────────────────────────────────────────────────────────────────
#
# Alle Namen sind woertlich uebernommen. Zwei tragen einen Buchstabendreher des Altsystems:
#
#   Message.ProejctIDIDX                            — und er steht auf ProcessID, nicht auf
#                                                     ProjectID
#   MessageBAMMandant.MandantIDSortIndexBAMTYpeIDX
#
# Beide werden NICHT korrigiert. Sie sind die Namen der Objekte in der Datenbank.
